# Installing Wolfpowers for Claude Code

Run these two commands in order:

```
/plugin marketplace add detair/wolfpowers
```

```
/plugin install wolfpowers@wolfpowers
```

Then restart your session. Wolfpowers skills will load automatically on session start.

## Updating

```
/plugin update wolfpowers
```

## Uninstalling

```
/plugin uninstall wolfpowers
```
